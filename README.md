# 2026 HIAS 计算机体系结构课程设计 | RISC-V CPU Design

本项目计划实现 RV32 双发射乱序处理器，完成动态分支预测、Cache、Sv32 MMU/TLB、独立 FP32 运算部件及 FPGA 验证。

当前处于规格与验证环境准备阶段，尚无已验收的自主 RTL。设计参数和时间表均为开发基线，不代表功能已经实现。
