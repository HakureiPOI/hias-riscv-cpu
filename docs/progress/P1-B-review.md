## 2 阻塞项

以下行号以最终交付 `a786255` 为准，可通过远端分支或 Git 对象读取；相关实现尚未合入 main。

### F01：JAL 被错误的 funct3 条件拒绝，期望生成器重复错误

- `rtl/frontend/p1_decode.sv:114–123` 在 JAL opcode 下要求 `instr[14:12]==0`。
- `verification/p1b/gen_decode_cases.py:130–134` 使用相同条件；第 295 行还将 `0x000012ef` 命名为 `ILL_JAL_F3`。第 266 行的 `JAL_neg` 也会被生成器错误标为非法。
- JAL 是 J-type，`instr[14:12]` 是立即数位，根本没有该 funct3 字段。例：**`0x000010ef` 应合法译码为 JAL x1，imm=+4096，rd_we=1、is_jump=1；当前 RTL 却置 illegal。** `0x000012ef` 同理是合法 JAL x5，imm=+4096。

依据锁定版 [v20260120 指令编码表](https://docs.riscv.org/reference/isa/v20260120/unpriv/rv-32-64g.html)与 [RV32I 跳转规范](https://docs.riscv.org/reference/isa/v20260120/unpriv/rv32.html)。JALR 的 funct3 检查仍需要保留。当前“76 项独立期望通过”不能证明 JAL 正确；期望不是从 DUT 输出生成，仍可能与 DUT 复制同一语义错误。

### F02：重定向未屏蔽外部握手，取消项可能被错误响应提前排空

1. `rtl/frontend/p1_frontend_core.sv:52–58,74–78` 只在时钟边沿清除输出寄存器，组合输出 `decoded_valid_o=out_valid_q` 未受有效 redirect 限制。保持旧译码结果时，消费者的 S0 accept=1 与有效 redirect 同拍，外部仍能看到 valid=1 并接受旧项，违反原任务“redirect 优先于同拍正常输出/接收”。TB 第 140–147 行遇 redirect 直接跳过接受检查，第 496 行还主动把 accept 改为 0，因此没有验证消费者持续可接收的边界。
2. `rtl/frontend/p1_fetch.sv:139–151` 先判断 `discard_q || redirect_i.valid`，后判断 `response_match`。已取消的请求 A 仍在途时，任意错误 ID/代次响应 B 都会使状态回 IDLE，并可能解除回绕阻塞；真正的 A 尚未返回。丢弃一个无主响应不能代替完成 A。身份匹配必须适用于正常项与取消项，只有匹配的终结响应才能释放其在途身份。
3. 非对齐 redirect 虽报告协议错误、保持目标 PC，却仍被其他路径按原始 `redirect_i.valid` 用于丢弃响应。应统一“合法重定向生效”的条件，验证非法目标不会错误释放在途项或伪造 Trap。

需要联合测试“最后一个代次分配→redirect 取消→错误身份响应→真正旧响应延迟返回→才允许回绕新分配”，不能以顺序回绕测试加普通错误响应测试替代该边界。保持已验收生产 RAM/桥，故障只在独立包装中注入。

### F03：TB 清除累计错误，定向场景绕过统一监视

- `verification/p1b/tb/tb_frontend.cpp:484–486` 每个随机种子开始前执行 `tb.errors=0`。这会抹掉此前基础/定向/回绕阶段的错误，也会抹掉前一个种子的错误；最终退出只检查最后保留的 errors。
- 例如定向阶段出现少量比较错误，三个随机种子随后正常，最终仍可能 exit 0。第一种子较晚失败时，后两种子补足总数也可能让总数检查通过。现有 `+mismatch` 在进入这些阶段前直接返回，不能证明正常完整运行保留早期失败。
- 第 313–338 行同拍响应/redirect 测试、第 384–395 行非法 redirect 测试手动推进时钟，绕过 `cycle()` 的请求/响应计数与检查；随后复位统计，最终 453/453 只代表末种子，不能证明全部定向阶段守恒。
- 请求停顿只检查 valid/ready，译码背压只比较 PC/指令；未覆盖完整载荷和最终握手边沿的稳定性。普通 fetch_gen 检查仅确认范围，不能证明与接受请求的身份对应。

R1 需要不清零的全局失败状态、全部工作边沿统一监视、独立请求所有权队列及完整的有效元数据检查。复位阶段可以分段统计，但必须显式静默/排空并报告，不能用复位隐藏未完成事务。
