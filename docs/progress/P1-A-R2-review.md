首轮发现的 34 位 PA 回绕和 size=3 原因码问题已在 R1 修复，R2 维持该实现并补足物理观察；Token 取消项+回绕联合测试继续通过。无需继续为这些已关闭项单独开修复轮。

## 3 使用边界与下一步

- RAM 是当前 128 KiB 仿真/后续移植基础，尚无 FPGA 推断、资源、频率或上板证据。镜像加载端口只在正常访问静默时使用，复位遵循外部事务已静默/排空的环境前提。
- 当前 TB 验证指定定向、三个固定种子与受控时序，不是任意并发的形式化证明。后续真实前端接入仍须检查其请求所有权、背压和旧响应处理；不能把模块夹具通过当成整机通过。
- P1-B 只实现 Fetch/Decode 与真实 RAM 集成取字，P1 活动槽为 1，共享结构保留双槽。可以输出取指/译码观察，不能输出伪退休或宣称程序已执行。执行/LSU/CSR/退休差分继续按 P1-C—F 推进。
- FPU/OS/板卡/EDA/Benchmark 课程口径仍待确认，P1-G 实机门禁保持未完成；这些等待不阻止 P1-B。
