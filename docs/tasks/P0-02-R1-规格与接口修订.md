| F01 对应 R01 | 修正六类 CSR 读写条件、五位立即数、权限/不存在 CSR 策略、CSR 地址/位域/复位/WARL 表、EBREAK/目标对齐/中断条件及阶段范围。补 P1 计数器、FENCE/返回的可执行规则。给各 P1 CSR 唯一确定的复位/写掩码/合法化规则，不保留“忽略或保留或归零”供实现者猜测。依据官方版本逐条核对；表、正文、测试计划一致。 |

| V02 接口 | Lint/导入/编译/运行通过；不同 ALU/分支/Load 符号操作能区分，CSR 立即数 31 不截断，异常 cause/tval 与预测索引不丢失。小型通道夹具覆盖零/一/两槽、两槽但只剩一个资源、连续背压后 S0/S1 各只接收一次、Flush/迟到响应、第二槽异常互斥输出及缩小代次宽度后的回绕/排空。只证明契约和夹具，不称 CPU 完成。 |
