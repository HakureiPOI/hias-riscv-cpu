## 1 阅读与边界

阅读设计书、P0-02-R2 验收、当前 ISA/CSR/地址图、共享类型、接口、退休契约和验证计划。冻结时的标量数据、反向接收、复位/在途契约是本轮输入。保护历史材料和现有工作，复用既有工具与看门狗。

本轮不写 Decode/ALU/LSU/CSR/ROB/Cache/MMU/FPU 功能模块，不运行伪 CPU 后宣称 RV32I/DiffTest 通过。板卡未定不阻止仿真骨架；不虚构 FPGA 资源、频率或上板结论。P1-A 完成只说明框架与 RAM/总线模块通过，不等于 P1 最小核完成。

## 2 实施内容

### A01 顶层与接口

- 新增明确分层的核心接口骨架、SoC/存储包装及文件列表，合理放入 `rtl/core/`、`rtl/soc/` 等目录。骨架导入共享包，P1 活动槽为 1，结构仍保留双槽类型；给出端口/文件说明及 P1-B 插入点，不搭建多套后续弃用的 CPU。
- 核心尚无取指执行时不自行发起事务；`commit_bundle_t` 的退休和 Trap 有效位保持零，不能为了验证输出成功标记而制造退休事件。复位 PC/后续复位向量使用 `RESET_VECTOR`，骨架内部状态有明确初值。
- 区分 `valid` 与 `ready` 的端口方向。存储请求/响应均可背压，载荷在未握手时稳定；同一请求只有一个完成响应，ID/代次原样保留。单事务在途可保守停顿，不要求零气泡或多端口吞吐。

### A02 RAM 和存储桥

- P1 仿真 RAM 为小端、`[0x80000000,0x80020000)`，128 KiB。地址检查使用完整 34 位 PA，不能截掉高两位后误命中 RAM。沿用单一平台配置和现有 RTL 常量一致性检查；不另外维护地址图。
- 接入 `mem_req_t`/`mem_resp_t`，明确请求接受、访问完成与响应接受的各个边沿；同一 Store 在响应背压期间不得重复写入。Read/Store 可由 TB 直接驱动，这仅是模块访问测试，不代表来自 CPU 提交。
- 支持自然对齐 byte/half/word；请求 wdata 为低位标量，byte mask 为目标四字节字内 lane。RAM 以访问地址逐字节写入，响应读值按宽度提取到低位并零扩展。符号扩展由未来 LSU 执行，不能要求桥在缺少有符号操作标记时猜测。
- RAM 起止边界、高 PA、地址越界、非法宽度/掩码、非对齐访问必须在写入前检查，返回明确错误，内存保持不变。读/写分别报告相应 access/misaligned cause；未来 Fetch 包装负责将读错误映射到 instruction access fault，不新增假造访存类型。
- 本轮 RAM 模块对 MMIO/预留/未定义地址返回错误；UART、结果寄存器与中断外设留给 P1-D/F/E。地址图 P1 栏是整个 P1 结束时的目标，不能因此称本任务已经实现外设。
- 已接受请求不能因上游 Flush 就凭空消失；读响应允许继续返回，调用者凭 ID/代次丢弃被取消结果。Store 在桥被接受后按不可取消事务收尾。复位采用“外部请求已静默/排空”的明确环境前提，空闲复位要可验证；不要通过清 RAM、丢在途响应掩盖边界问题。
- RAM 内容初始化与复位控制状态分开：说明仿真载入方式，或由 TB 先写入已知数据；未初始化位置不作为确定读值。避免用每拍/复位清空整个 RAM 的写法妨碍后续 FPGA 推断；这不是本轮综合/上板通过声明。

### A03 验证与 P0 补测

- 新建实际模块 TB，以独立字节数组/事务队列为预期，逐项比较响应 ID/代次、错误、数据和内存变化；不能以 DUT 自己读出的值生成预期。
- 覆盖 RAM 首/末字节、首/末字、四种 byte lane、两种 half lane、word、部分写保持邻接字节、连续同址读写；byte/half 响应必须符合低位零扩展。检查非法请求无内存副作用。
- 施加请求停顿、响应连续背压、可控访问延迟、连续事务和已接受请求后的 Flush/取消模拟，按接受边沿记账。至少三个固定种子、合计不少于 1,000 笔合法/非法混合事务；配合定向边界，不以数量代替缺陷关闭。
- 补 P0 Token 联合用例：缩小代次，回绕前仍有已取消的匹配外部响应未到；新分配必须持续阻塞，在真正收尾后恢复；核对取消项与活动项数量，不能只测普通活项排空。保留 P0 全部历史证据，补测日志写入本轮目录。
- 给 RAM TB 的错误检测与运行预算各一条受控负向探针：真实比较路径发现一次预期/读值不一致并非零退出；受控挂起由主机看门狗在规定时间非零终止。复用已有机制，不另建通用验证框架。
